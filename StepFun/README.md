# StepFun | 阶跃星辰

## 关于 Phaser

本项目的所有小游戏均基于 [Phaser 3](https://phaser.io/) 开发。

- **Phaser** 是一个开源、轻量的 HTML5 游戏框架，专注于桌面与移动端浏览器中的 2D 游戏开发。
- 项目已在根目录内置 `phaser.min.js`（Phaser 3 运行时），各 HTML 文件通过相对路径直接引用，**无需联网或额外安装依赖**，双击打开即可运行。
- 所有游戏均采用原生 Web Canvas / WebGL 渲染，纯前端实现，不依赖任何后端服务。
