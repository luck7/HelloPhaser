支持三种内容：① 本程序保存的 JSON 棋谱；② 传统棋谱文本（1. 炮二平五 砲8平5，可整局粘贴）；③ FEN 局面串。
也可以点「选择文件」读取 .json / .txt / .fen 文件。
点击自己的棋子选中（绿点=可走，红圈=可吃），再点目标位置落子。
记谱采用标准四字式「名称 + 起始纵线 + 动作 + 目标」：红方纵线从右往左 一~九，黑方从左往右 1~9； 车/砲/将/兵 记步数，马/相/仕 记目标纵线。例：炮二平五、马八进七、砲8平5、马8进7；同纵线有多个同类棋子时用前/中/后区分（如前车进一）。
右侧棋谱可点任意一手跳转；复盘用按钮或 ← → 方向键逐步推演；保存棋谱导出 JSON、保存局面导出 FEN，加载支持 JSON / 棋谱文本 / FEN。
