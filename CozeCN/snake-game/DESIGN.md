# DESIGN.md

## 气质与意象

- **核心意象**：2000 年诺基亚 3310 的单色 LCD 掌机屏幕——一块深豆绿底、近乎墨黑像素的老式点阵屏，在磨砂炭灰机身里安静发着绿光。
- 复古、克制、像素化；没有渐变、发光、玻璃拟态。像一台真实通电的老设备，而不是"科技风游戏页"。
- 画面中所有元素都必须像 LCD 点阵画出来的：硬边、无抗锯齿感、低分辨率网格。

## 视觉策略

- 游戏本体（蛇、食物、棋盘）完全由 Phaser 在 Canvas 内以 Graphics 像素块绘制。
- 页面外壳模拟掌机：磨砂炭灰机身包裹一块绿色 LCD，HUD 即"液晶屏读数"。
- 棋盘为正方形网格，21 × 21 格；背景铺极淡的网点纹理暗示 LCD 点阵。
- 蛇身为实心圆角像素块，头部比身体略大并带两个像素眼睛，眼睛方向随移动方向变化。
- 食物为单个墨黑像素方块，带轻微"呼吸"（尺寸周期性缩放），像在闪烁的像素点。

## 配色方案

| 用途 | 色值 | 意象来源 |
| --- | --- | --- |
| 机身背景 | `#23262b` | 炭灰磨砂塑料机身 |
| LCD 底色 | `#9bbc0f` | 诺基亚 LCD 经典浅豆绿 |
| 棋盘底 | `#9bbc0f` | 同上，全屏统一 |
| 点阵网格 | `#8cab0e` | 比 LCD 底略深，若隐若现 |
| 蛇 / 食物 / 文字 | `#0f380f` | LCD 墨黑（深墨绿） |
| 覆盖层底 | `rgba(15, 56, 15, 0.72)` | 断电般的深绿蒙层 |
| 强调（最高分） | `#306230` | LCD 中间灰度绿 |

## 字体排版

- 像素与数字：**Press Start 2P**（Google Fonts，国内走 `fonts.googleapis.cn`）。
- HUD 数字（SCORE / BEST）用大号像素字，字距拉开，像液晶屏读数；标签用小号大写像素字。
- 说明性中文小字使用系统等宽字体（`ui-monospace`），不混入圆体或衬线。
- 页面只有一处大标题："SNAKE"。

## 动效与交互

- 蛇按固定节拍（tick）整格移动，初始 150ms / 步，每吃一个食物加快 3ms，最快 70ms / 步。
- 食物持续轻微呼吸缩放（sin 波），是屏幕上唯一"闲置时也在动"的元素。
- 吃食物：短促 8-bit 上扬"嘀"音；死亡：两音节下降"嘀—嘟"音（WebAudio 方波，不加载音频文件）。
- 开始 / 结束有半透明深绿覆盖层，按键即可开始 / 重开，无花哨转场。
- 操作：方向键 / WASD 转向，空格或回车开始 / 重开；移动端支持滑动手势，并在屏幕下方提供三键式方向键（◀ ▲ ▼ ▶）。

## 设计禁忌

- 不要渐变、霓虹发光、阴影投射、毛玻璃。
- 不要"科技蓝紫"配色，不要圆角大卡片漂浮在浅色网页背景上。
- 蛇不要画成连续平滑曲线，必须是一格一格的像素块。
- 不要使用表情符号图标；方向键只用纯字符 ▲ ▼ ◀ ▶。
- 音效不使用外部音频文件。
