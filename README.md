# HelloPhaser

Learning Phaser - HTML5 Game Framework



## Phaser.js（HTML5 游戏框架）的官方网站：

官方网站：https://phaser.io/
官方文档：https://docs.phaser.io/
在线示例：https://phaser.io/examples
GitHub（源代码）：https://github.com/phaserjs/phaser
快速创建项目：

``` bash
npm create @phaserjs/game@latest
```

Phaser 主要用于使用 JavaScript（JavaScript，网页编程语言）或 TypeScript（TypeScript，JavaScript 的类型增强版）开发 2D 网页游戏，支持 Canvas（画布渲染）和 WebGL（网页图形接口）。
